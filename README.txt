MY AI FILMMAKER — VERSION 1.1
Now includes the custom MAF app icon and PWA files.

PHONE INSTALL (recommended)
1. Upload the entire folder to a web host that gives you HTTPS.
2. Open the resulting HTTPS address in Chrome on Android.
3. Chrome menu -> Add to Home screen / Install app (wording can vary).
4. The app will appear on your home screen as "AI Filmmaker" with the MAF icon.

IMPORTANT
Do not upload only index.html. Keep manifest.webmanifest, sw.js and the icons folder beside it.

EASY FREE HOSTING OPTIONS
- GitHub Pages: good for a permanent personal site, but requires a GitHub account.
- Netlify: can host a static site and is beginner-friendly.
- Cloudflare Pages: another static hosting option.

VERSION 1.1 still does not contain a video AI model. It is the private filmmaking workspace. The next build can add AI generation through official APIs or local/open-source models.
